# Instruções do Projeto (CLAUDE.md)

## Stack Tecnológica
- Frontend: HTML5, CSS3, JavaScript (Vanilla / ES6+)
- Backend: Firebase
- Banco de Dados: Firebase
- Versão e Controle: Git / GitHub

## Regras de Desenvolvimento e Padrões
1. **Análise Prévia:** Sempre analise a estrutura dos arquivos existentes antes de propor modificações.
2. **Preservação de Funcionalidades:** Nunca quebre funcionalidades existentes ao implementar melhorias ou corrigir bugs.
3. **Comandos de Teste:** Informe sempre como testar as alterações realizadas.
4. **Simplicidade:** Priorize códigos limpos, fáceis de dar manutenção
